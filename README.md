# atomon.si

Static site for https://atomon.si (GitHub Pages, custom domain in `CNAME`).

- `/` and `/el/`: company home (English / Greek). The English home links to the product pages and still lists each app’s privacy policy and terms.
- `/e-shop-builder/`: AI e-shop builder (early access)
- `/shopify-avatar/`: Shopify AI avatar shopping assistant (early access)
- `/idolingo/...`: copied from the idolingo repo `legal/idolingo/` (generated there by `scripts/build-legal-pages.ts`; edit there, then copy)
- `/to-paixnidi-mas/...`: copied from the to-paixnidi-mas repo `legal/to-paixnidi-mas/` (generated by `scripts/legal-pages.ts`; edit there, then copy)
- `/falagga/...`: written here (no data collected)

No scripts, trackers, or external resources.
